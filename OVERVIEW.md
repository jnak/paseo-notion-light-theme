Notion Light adds a light theme to Paseo built from the colors of Notion's light theme. The values were read from the Notion desktop app's own color tokens: warm off-white surfaces, Notion's near-black text and gray secondary text, its soft borders, and Notion blue as the accent. Surfaces step down in the same order as Paseo's built-in light theme, so hover, sidebar, and selection states read the same way. Paseo fills user messages with the border color, so borders use Notion's lighter border to keep messages close to Notion AI's. Diff colors, status dots, and the composer outline stay Paseo's defaults, because themes cannot change them. The theme appears under Settings → Appearance. It contains theme data only: no settings, no server component, and no network or file access. Requires Paseo 0.11.0 or later.
